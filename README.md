# Homebrew Minto

Minto macOS 앱의 공식 Homebrew Cask 저장소입니다.

## 설치

첫 Cask 릴리스가 병합된 후 다음 명령으로 설치할 수 있습니다.

```bash
brew install --cask zhsks311/minto/minto
```

## 지원 환경

- Apple Silicon
- macOS 14 이상

## 최초 실행

Minto는 현재 Apple 공증을 받지 않은 preview 앱입니다. macOS가 최초 실행을 차단하면 Finder의 응용 프로그램에서 Minto를 우클릭하고 **열기**를 선택하세요.

이 Tap은 Gatekeeper quarantine을 자동으로 제거하지 않습니다.
